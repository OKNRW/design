# Logos

- `oknrw-logo-rechteck-eng.png` — dasselbe Leitlogo ohne Randweißraum, für Kopfbereich und mobiles Menü.
- `oknrw-logo-rechteck.png` — Leitlogo (Rechteck-Redesign), 1206 × 282 px, mit Claim. Wortmarke schwarz, „NRW“ in Grün #3AAA35, Grau #8EA6B2, Rot #E30613. Eine Vektorfassung dieses Redesigns liegt noch nicht vor.
- `oknrw-quadrat-alt.png` — Quadratmarke in der bisherigen Schrift. Wird an das Redesign angeglichen (Entscheidung 2); bis dahin nur dort verwenden, wo ein Quadrat zwingend ist.
- `oknrw-quadrat-alt-weiss.svg` — dieselbe Quadratmarke mit weißem „OK“ für dunkle Flächen; Farben der NRW-Buchstaben aus Satz B (#6AA842, #93A4B0, #C20E1A), daher ebenfalls abzulösen.

Schutzraum um das Logo: mindestens die Höhe des „N“. Mindesthöhe digital (zugeschnittene Fassung): 28 px (mobil), 40 px (Kopfbereich). Auf Mint ist das Logo zulässig; dafür ist eine Mint-Variante mit dunklerem „R“ vorgesehen (noch zu erstellen).
