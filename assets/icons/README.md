# Icons

Lucide 0.400.0 (ISC-Lizenz), 24 px Raster, Strichstärke 2, runde Enden. Einfarbig: in Komponenten als Inline-SVG mit `stroke="currentColor"`, damit sie die Textfarbe übernehmen. Die Dateien hier sind die Originale; in Komponenten werden sie inline eingesetzt.

Größen: 16 px in Menüs und Brotkrumen, 20 px neben Text, 24 px in Meldungen und Icon-Buttons. Icons ohne Text brauchen ein `aria-label`; neben Text sind sie `aria-hidden`.

Enthalten: menu, x, chevron-right, chevron-down, search, arrow-right, arrow-up-right, external-link, calendar, map-pin, mail, rss, linkedin, info, triangle-alert, circle-check, check, pause, play, vote, database, tent, file-code-2.
