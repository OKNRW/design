# Badge

Ein bis zwei Wörter für Kategorie, Format oder Status.

- Form: Pille (`radius-full`).
- Standard (`bg-subtle`): Kategorie oder Thema.
- Kontur: Format, z. B. „Stellungnahme“.
- Dunkel (`text-primary` als Fläche): Termine, Projektnamen.
- Hinweis (`text-highlight` als Fläche, Schrift `text-on-dark`, 6,2:1): seltene Hervorhebung wie „Neu“ oder „Frist läuft“; höchstens eine je Ansicht.
- Badges sind nicht klickbar. Für Filter einen Button verwenden.

Klassen: `ok-badge` plus `--outline` | `--dark` | `--hinweis`.
