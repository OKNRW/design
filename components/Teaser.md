# Teaser

Verweist auf ein Projekt oder einen Bereich, mit genau einer Handlung.

- Fläche `bg-mint`; auf Mint-Sektionen stattdessen `bg-base` verwenden.
- Titel `h3`, ein bis zwei Sätze Text, ein sekundärer Button. Externe Ziele mit Symbol „externer Link“.
- Unterprojekte (O-Mat, Datenatlas, Barcamp) erscheinen als Teaser innerhalb der Dachmarke; eigene Farben nur im Bild, nicht in der Fläche.

Klasse: `ok-teaser`.
