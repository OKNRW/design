# Sessionboards OKNRW-Barcamp

HTML-Snippets für einen WordPress-Block „Individuelles HTML“. Jede Datei enthält Markup, CSS und Skript; keine weiteren Dateien nötig.

| Datei | Inhalt |
|---|---|
| `barcamp-2025-notizen.html` | Notizen aller Sessions 2025: 6 Tracks × 4 Runden, Suche, „nur mit Notizen“, Detailfenster |
| `barcamp-2026-sessionboard.html` | Sessionboard 2026 mit Hashtag-Filter |

Einfügen: Datei über „Raw“ öffnen, alles markieren (Strg+A), kopieren und im Block einfügen.

Hinweise
- Die Skripte enthalten keine Backslashes, weil WordPress sie beim Speichern entfernen kann.
- Das Board 2025 hat die ID `oksp25`, das Board 2026 die ID `oksp`; beide können auf einer Seite stehen.
- Daten 2025: aus der Seite „Rückblende OKNRW-Barcamp 2025“ (Stand 2026-11-25). Keine Uhrzeiten, Räume und Hashtags vorhanden; Sessiongebende nur, wo die Notizen sie nennen.
